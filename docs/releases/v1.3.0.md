# ROMS 1.3 — Turn your knowledge into reusable skills

Your local AI should be able to put your knowledge to work. ROMS now turns imported procedural guides, runbooks and checklists into reusable, source-backed skill drafts automatically. Add a guide once, then find its procedure through the local workspace, CLI or your AI client's MCP tools.

## What is new

- **Automatic procedural drafts.** Recognizable procedures become skill candidates as documents are indexed, with no additional model service or cloud account.
- **A growing skills library.** New topics add new drafts. Matching section headings collect additional procedures; identical text is deduplicated, and different variants retain their original order and citations.
- **Sources you can inspect.** Open contributing passages, see document checksums and track the exact revision behind a draft. Changed or removed sources update the current library.
- **Feedback with context.** Record what worked and what needs improvement. Observations remain visible across revisions, while feedback counts apply only to the version that was reviewed.
- **Portable exports.** Download a reviewable `SKILL.md` from the workspace or CLI. Exports include the source revision and references, and refuse stale revision requests.
- **Four new MCP tools.** Search, inspect, refresh and give feedback on knowledge-derived skills. Discovery works in the read-only profile; mutations require the local profile.

This is especially useful for local AI workflows built around personal documentation, repeated maintenance tasks, project runbooks and troubleshooting guides. ROMS connects the information you have saved with procedures you can find and reuse.

## Start using it

Update ROMS and launch `python roms.py knowledge` in your installed environment. Open **Skills from your knowledge**, import a procedural guide, and review the generated draft. Existing indexes backfill when the knowledge workspace or Python MCP server starts. Native MCP users can first run `python roms.py skills refresh`.

See the [usage guide](../knowledge-skills.md) for CLI examples, all four MCP tools, source handling and limits.

## What this release does—and its limits

Drafting uses deterministic extraction of structured procedures. It does not train a model, invent procedures, resolve conflicting sources, install skills into an agent, or execute them. More relevant source material can expand coverage; more files alone do not guarantee better skills. Review drafts before use. Exported files are snapshots and do not update themselves.

The reference review covered 132 ZIP archives plus the prioritized enhancement and skills folders. Selected design ideas were implemented in original ROMS code; upstream agents, installers and third-party code were not bundled. The [reference inventory](../reference-review.md) records the review boundary and dispositions.
